Frequently asked questions

Is StudentHub free?

Yes. The core student tools are free. Premium features can be introduced later without removing the useful free tools.

Do I need an account?

No. The current core tools work without an account. A future account system can provide cloud sync and saved history.

Can students worldwide use it?

Yes. The calculations and utilities are designed as general-purpose student tools rather than for one specific institution.

What is the CV Builder?

StudentHub connects to the official CV Builder so students can create a professional CV for internships, jobs and applications.
